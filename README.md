# Gerador de Senhas

Um projetinho simples em Python com interface gráfica para gerar senhas aleatórias e seguras de forma rápida.

## O que ele faz?
- Escolha o tamanho da senha (de 6 a 32 caracteres)
- Selecione se quer usar letras, números e símbolos
- Suporte para alternar entre Português e Inglês
- Botão para copiar a senha direto para a área de transferência com um clique

## Como usar
Se você quiser só baixar e usar o programa pronto sem precisar mexer em código:
1. Vá na aba **Releases** aqui do lado direito do repositório.
2. Baixe o arquivo executável (`.exe`).
3. Abra e use!

## Como rodar o código
Se quiser rodar direto pelo código fonte:
1. Tenha o Python instalado na sua máquina.
2. Clone ou baixe este repositório.
3. Instale o Tkinter (geralmente já vem padrão com o Python) e execute:
   ```bash
   python Password-generator.py
